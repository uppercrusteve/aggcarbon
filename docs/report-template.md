## 2. 公式与单位

- p_i = m_i / Σm；MWD = Σ(p_i·d_i)；GMD = exp(Σ(p_i·ln d_i))；R>0.25 = Σ_{d_i>0.25} p_i
- M (Mg/ha) = BD (g/cm3) × depth (cm) × 100
- stock_i (Mg/ha) = M × p_i × SOC_i (g/kg) / 1000
- ESM：stock × M_ref / M_sample
- CPI = POC_treat / POC_ref；CMI = CPI × (SOC_treat / SOC_ref) × 100；参照 = 100

| 指标 | 单位 | 备注 |
|---|---|---|
| MWD / GMD | mm | 名义直径加权 |
| R>0.25 | 0–1 | 大团聚体质量比例 |
| SOC / POC / MAOC 储量 | Mg/ha | 注明是否 ESM |
| CPI | 比值 | 参照 = 1 |
| CMI | 指数 | 参照 = 100 |
